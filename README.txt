TBANK — кошелёк Stars и Gram для StaticGram
============================================

Это стартовый проект, а не официальный продукт Т-Банка.
Возможности:
- единая SQLite-база;
- баланс Stars и Gram, обеспеченный реальными средствами (1:1 балансом бота);
- пополнение: оплата счёта в Stars (XTR) или Gram через Mini App или в чате с ботом;
- вывод: реальные Stars/Gram на аккаунт StaticGram через withdrawStarBalance / withdrawGramBalance;
- переводы между пользователями TBank по @username (не по id);
- подарочные чеки: одноразовый код на сумму, бот присылает чек фото-карточкой;
- Mini App с настоящей авторизацией StaticGram (проверка подписи initData);
- бот @tbank_bot с меню кнопок: Отправить, Пополнить (выбор ⭐/🪙 кнопками),
  Вывести, Чек, Баланс, История, Помощь.

ВАЖНО:
Баланс в TBank — это средства, доверенные боту: пополнение переводит реальные
Stars/Gram на баланс бота, вывод отправляет их со счёта бота на аккаунт пользователя.
Bot API не позволяет прочитать баланс произвольного пользователя StaticGram,
поэтому в приложении показывается именно баланс TBank.

БЫСТРЫЙ ЗАПУСК НА WINDOWS
1. Установите Python 3.11 или новее.
2. Скопируйте .env.example в .env и вставьте STATICGRAM_TOKEN (выданный @BotFather в StaticGram).
   Локальный файл .env уже лежит рядом — для локальной разработки ничего менять не нужно.
3. Запустите start.bat — поднимется API на http://127.0.0.1:8000.
4. Во втором окне запустите бота:  py bot.py
5. Напишите боту @tbank_bot в StaticGram /start — он пришлёт кнопку Mini App.
   Для локального теста откройте http://127.0.0.1:8000 в браузере
   (вне StaticGram приложение работает в demo-режиме).

КОМАНДЫ БОТА (и то же самое в Mini App)
Управление — кнопками меню под полем ввода:
- 📤 Отправить — перевод по @username получателя.
- 💰 Пополнить — сначала кнопки выбора валюты (⭐ Stars / 🪙 Gram), затем сумма.
- 💸 Вывести — выбор валюты кнопками, затем сумма.
- 🎟 Чек — создать чек (придёт фото-карточка с кодом вида K7QX-M92T-4LPD)
  или активировать чужой чек кодом. Чек одноразовый.
- 📊 Баланс, 📜 История — состояние счёта и операции.
Команды тоже работают:
- /balance — баланс Stars и Gram.
- /topup stars 100 — счёт на пополнение на 100 Stars.
- /topup gram 2.5 — счёт на пополнение на 2.5 Gram (минимум 0.01).
- /withdraw stars 50 — вывести 50 Stars на аккаунт StaticGram.
- /withdraw gram 1.5 — вывести 1.5 Gram.
- /send @username stars 10 — перевод по @username.
- /cheque stars 25 — создать чек на 25 Stars.
- /activate K7QX-M92T-4LPD — активировать чек.
Перевод по @username работает, только если получатель хотя бы раз открывал
бота или Mini App (иначе его username неизвестен системе).

КАК РАБОТАЮТ ПЛАТЕЖИ
1. Пополнение:
   - Mini App: /api/topup -> createInvoiceLink / createGramInvoiceLink ->
     Telegram.WebApp.openInvoice -> пользователь оплачивает счёт.
   - Чат: /topup -> sendInvoice / sendGramInvoice.
   - Бот получает pre_checkout_query (ответ ok в течение 10 секунд),
     затем successful_payment; сумма зачисляется на счёт TBank.
     Защита от двойного зачисления: таблица payments с уникальным charge_id.
2. Вывод: withdrawStarBalance(user_id, star_count, request_id) /
   withdrawGramBalance(user_id, nanoton_amount, request_id).
   Сначала подтверждение StaticGram API, потом списание со счёта TBank;
   при ошибке API баланс не трогается, операция помечается failed.
3. Переводы: внутренние (с баланса TBank отправителя на баланс получателя).

КАК РАБОТАЕТ АВТОРИЗАЦИЯ
- Mini App отправляет на backend строку Telegram.WebApp.initData.
- Backend проверяет её подпись HMAC-SHA256 (стандартный алгоритм Telegram, ключ — токен бота)
  и свежесть auth_date, затем выдаёт сессионный токен на 24 часа.
- Без токена бота (пустой STATICGRAM_TOKEN) сервер работает в demo-режиме:
  вход по user_id без проверки, пополнение и вывод отключены. Только для локальных тестов!

НАСТРОЙКА ЧЕРЕЗ .env / ПЕРЕМЕННЫЕ ОКРУЖЕНИЯ
- STATICGRAM_TOKEN — токен бота. НЕ публикуйте его и не отправляйте в чаты;
  если токен утёк — перевыпустите через @BotFather (/revoke).
- ADMIN_IDS — id администраторов через запятую.
- MINI_APP_URL — публичный https-адрес Mini App для кнопки в боте.
- API_BASE — адрес backend, по умолчанию http://127.0.0.1:8000.
- CORS_ORIGINS — разрешённые домены через запятую. По умолчанию "*" — ТОЛЬКО для локальной
  разработки! Перед публикацией задайте точный домен Mini App.

ДЛЯ ПУБЛИКАЦИИ
- frontend (index.html) — на Cloudflare Pages или любом статическом хостинге с HTTPS;
- backend (main.py) — на сервере с HTTPS и постоянным хранилищем;
- в index.html замените API_BASE (или задайте window.API_BASE до загрузки скрипта);
- задайте MINI_APP_URL и CORS_ORIGINS в .env на сервере;
- бот (bot.py) — запущен на сервере рядом с backend;
- следите, что на балансе бота достаточно средств для выводов пользователей
  (обеспечение кошелька: getMyStarBalance / getMyGramBalance).

ПРОВЕРКА

- py test_wallet.py — юнит-тесты кошелька и команд бота (Bot API подменён).
